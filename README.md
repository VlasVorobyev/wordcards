## 📖 Описание проекта

WordCards — это веб-приложение для изучения иностранных слов в формате карточек и квиза.

## 🎯 Функционал

### Веб-интерфейс
- ✅ Создание, просмотр, редактирование карточек (CRUD)
- ✅ Сортировка карточек (по слову, переводу, дате, случайно)
- ✅ Валидация форм с понятными сообщениями об ошибках
- ✅ Адаптивный дизайн на Bootstrap 5
- ✅ Квиз для проверки знаний

### Telegram-бот
- ✅ Интеграция с Telegram API
- ✅ Квиз в формате "слово → перевод"
- ✅ Полная синхронизация с базой данных Django

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| Django 5.x | Веб-фреймворк |
| SQLite | База данных |
| Bootstrap 5 | Стили и иконки |
| python-telegram-bot | Telegram-бот |
| Pylint | Статический анализ кода |
